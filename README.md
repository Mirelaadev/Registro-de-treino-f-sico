# Sistema de Registro de Treinos

## 📖 Sobre o projeto

Este projeto foi desenvolvido como uma **atividade da faculdade**.

Inicialmente, a proposta era aplicar os conceitos de **Programação Orientada a Objetos (POO)** em Java. Posteriormente, o sistema foi expandido para incluir conceitos de **Banco de Dados**, utilizando o **MySQL** para armazenar as informações.

A aplicação funciona via **terminal**, permitindo que o usuário cadastre treinos e, em seguida, cadastre exercícios vinculados a cada treino, representando o relacionamento entre as entidades no banco de dados.

## ✨ Funcionalidades

- Cadastro de treinos;
- Cadastro de exercícios associados a um treino;
- Listagem dos treinos cadastrados;
- Listagem dos exercícios de cada treino;
- Integração com banco de dados MySQL.

## 🛠️ Tecnologias utilizadas

## 🚀 Como executar

1. Clone o repositório:

```bash
git clone <url-do-repositorio>
```

2. Configure o banco de dados MySQL e execute o script SQL do projeto.

3. Compile os arquivos Java:

```bash
javac *.java
```

4. Execute a aplicação:

```bash
java Main
```
